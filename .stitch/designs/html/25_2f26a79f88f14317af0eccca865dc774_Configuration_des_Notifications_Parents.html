Notifications Automatiques

Configurez les messages envoyés aux parents lors du traitement des dossiers d'admission.

code Variables de Substitution

Utilisez ces variables dans vos messages. Elles seront automatiquement remplacées par les informations réelles du dossier.

{nom_eleve} Nom complet de l'élève
{prenom_eleve} Prénom de l'élève
{classe_demandee} Classe d'admission
{docs_manquants} Liste des documents
{motif_refus} Raison du rejet
{date_limite} Date d'échéance
